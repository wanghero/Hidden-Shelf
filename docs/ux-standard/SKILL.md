# UX 规范 v2.0.0

目标只有两个：**所有项目看起来出自同一只手**，以及**不用每次重新交代设计要求**。

**风格：Soft UI 卡片风 + Material 波纹反馈。**
- 浅灰页面底上放白色圆角卡片，柔和阴影，舒适的间距。
- 主色实心填充做选中态和主按钮，带同色投影。
- 统计卡片使用色底图标块和大号粗体数字。
- 所有可点击元素按下时有从点击点扩散的波纹。

参考实物：同目录没有截图，风格样稿见用户的 `~/Claude-Code/Temp2/ux-test/soft.html`（静态视觉）和 `index.html`（按本规范实现的完整测试页）。

规则分两级：**必须**（违反即返工）和**建议**（有理由可以偏离，要在回复里说明理由）。

## 0. 开工流程

1. 新项目：把同目录的 `tokens.css` 和 `ripple.js` 复制到项目里（如 `src/styles/tokens.css`、`src/lib/ripple.js`）。`tokens.css` 作为全局样式第一个引入；`ripple.js` 在应用入口引入一次（或调用 `initRipple()`）。
2. 已有项目：先看项目里有没有 `tokens.css` 或同名变量；有就沿用，没有就引入，然后**只在改到的地方**迁移，不做无关的大改。
3. 主色默认靛蓝 `#4F46E5`。用户为某个项目指定了别的品牌色时，改 `--primary` 系列（浅色、暗色、`prefers-color-scheme` 三处），并验证对比度（见第 8 节）。
4. 用 Tailwind 的项目：在 `tailwind.config` 里把 colors / fontFamily / borderRadius / spacing / boxShadow 映射到这些 CSS 变量，**不要**使用 Tailwind 默认调色板（`bg-indigo-600` 之类）。

## 1. Token（必须）

- 颜色、字号、间距、圆角、阴影、层级**只能**引用 `tokens.css` 里的变量。组件里出现裸色值（`#xxx`、`rgb()`、`bg-gray-100`）视为违规。
- 需要新 token 时先加到 `tokens.css`（浅色、暗色、`prefers-color-scheme` 三处同步），再使用。

### 颜色角色
| 变量 | 用途 |
|---|---|
| `--bg` | 页面背景（浅灰，用来衬托卡片） |
| `--surface` | 卡片、侧栏、弹窗、下拉菜单 |
| `--surface-hover` | 列表项、导航项 hover |
| `--fg` / `--fg-muted` / `--fg-subtle` | 正文 / 次要文字 / 时间戳和占位符 |
| `--border` / `--border-strong` | 卡片描边和分割线 / 输入框和次级按钮描边 |
| `--primary` + `--on-primary` | 实心填充：主按钮、侧栏当前项、勾选框 |
| `--primary-text` | 链接、强调文字 |
| `--primary-soft` | 浅色底：徽标、胶囊标签、头像块 |
| `--blue / --success / --warning / --danger` 及 `-soft` | 状态色；`-soft` 做色底、本色做图标和文字 |

### 主色使用纪律（必须）
- 每个项目**只有一个**主色。
- 实心主色只用在：主按钮（每屏最多一个）、侧栏当前项、勾选/开关的选中态。
- 主色不做大面积背景、不做渐变、不给标题文字上色。
- 状态色只表达状态（统计卡片的图标块按"数据含义"配色：总量蓝、成功绿、等待琥珀、失败红）。

### 字号与字重
| 用途 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 28px `--text-xl` | 700 |
| 统计大数字 | 34px `--text-display`，等宽数字 | 700 |
| 卡片标题 | 18px `--text-lg` | 600 |
| 列表主标题、侧栏导航 | 15px `--text-md` | 600 / 500 |
| 正文 | 14px `--text-base` | 400 |
| 次要信息 | 13px `--text-sm` | 400 |
| 辅助说明、徽标 | 12px `--text-xs` | 500–600 |

700 只用于页面标题、统计大数字和品牌名。

### 间距、圆角、阴影
- 4px 网格，只用 `--space-*`。卡片内边距 24px；卡片之间 24px；列表项内边距 12–16px；页面边距桌面 40–48px、手机 16px。
- 圆角：卡片和弹窗 16px（`--radius-lg`）；按钮、输入框、导航项、列表项、图标块 12px（`--radius`）；徽标和小按钮 8px（`--radius-sm`）。
- 阴影：卡片 `--shadow-card`，可点击卡片 hover 时 `--shadow-card-hover`；主按钮和侧栏选中项 `--primary-shadow`；浮层 `--shadow-popover`。不自己写阴影值。

### 字体
- `Geist` + `Geist Mono`，中文回退苹方/雅黑（已写在 `--font-sans`）。
- 加载方式：npm 包 `geist` 或 Google Fonts（`family=Geist:wght@400;500;600;700&family=Geist+Mono:wght@400;500`），`font-display: swap`。
- 等宽字体用于：代码、ID、哈希、端口号、文件路径、日志。数字列、计时器、统计数字加 `font-variant-numeric: tabular-nums`。

## 2. 视觉禁用清单（必须）

以下一律不做：
- 装饰性渐变：紫蓝渐变背景、渐变按钮、渐变文字
- emoji 当图标或标题装饰（✨🚀📊 之类）
- 玻璃拟态（backdrop-blur 半透明卡片）、霓虹光晕、发光描边
- 卡片里再套**带阴影**的卡片（卡片内部的子项只能用 1px 描边或 hover 底色区分）
- 工具界面里出现"居中大标题 + 三列特性卡片"的落地页结构
- 无意义的装饰图形、插画、背景纹理
- 超出 token 的圆角和阴影（例如 24px 圆角、黑色重阴影）
- 每张统计卡片用不同的强调色做**大面积**背景（色彩只出现在 48px 图标块里）

**图标**：只用线性图标，线宽 2（侧栏 1.75），尺寸 16–18px（按钮/行内）、20px（侧栏）、22px（统计卡片图标块内）。React 用 `lucide-react`，Vue 用 `lucide-vue-next`，Svelte 用 `lucide-svelte`，纯 HTML 用 lucide 的 SVG。同一项目不混用图标库。

## 3. 布局骨架（必须）

```
┌─────────────┬──────────────────────────────────────┐
│ ⚡ 品牌名    │  页面标题 28px                [+ 主操作] │
│             │  副标题 / 系统状态                        │
│ ▓▓ 当前项 ▓▓ │                                        │
│  导航项      │  ┌────┐ ┌────┐ ┌────┐ ┌────┐           │
│  导航项      │  │统计│ │统计│ │统计│ │统计│  ← 统计卡片 │
│  导航项      │  └────┘ └────┘ └────┘ └────┘           │
│             │  ┌──────────────┐ ┌────────┐            │
│ ─────────── │  │ 主内容卡片     │ │ 侧卡片  │            │
│  设置        │  └──────────────┘ └────────┘            │
│  ◐ 主题 中/EN│                                        │
└─────────────┴──────────────────────────────────────┘
 260px，--surface，右侧 1px border       --bg 浅灰背景
```

- **侧栏**：宽 260px，`--surface` 背景。顶部品牌区（图标 + 品牌名，700），中间导航，**底部固定放**：设置、退出登录、主题切换、语言切换、版本号。
- **导航项**：高 48px，圆角 12px，项与项间距 6px，图标 20px + 15px 文字（500）。当前项：`--primary` 实心填充 + `--on-primary` 文字和图标 + `--primary-shadow`。其余项：`--fg-muted`，hover 时 `--surface-hover`。
- **没有顶栏**：页面标题直接放在内容区顶部，主操作按钮放在标题右侧（高 44px，带 `--primary-shadow`）。一个页面只有一个主操作。
- **内容区**：最大宽 1280px，桌面内边距 40px 48px。区块之间 24–28px。
- **统计卡片**：一行 4 张（手机 2 张）。结构自上而下：48px 色底图标块（圆角 12px，`--xxx-soft` 底 + `--xxx` 图标）→ 13px 标签 → 34px 数字 → 胶囊形补充说明（`--xxx-soft` 底）。
- **内容卡片**：卡片头（18px 标题 + 13px 副标题，底部 1px 分割线）+ 卡片体 + 可选卡片脚（链接放左下）。
- 表单、设置页、文章类内容限制在 640px 宽以内。

### 响应式（桌面优先，手机可用）
- 断点：`< 768px` 为手机。
- 手机上：侧栏收成抽屉（页面左上角出现汉堡按钮，遮罩 `--overlay`）；页面边距 16px；统计卡片两列；两栏布局变单栏（`grid-template-columns: minmax(0, 1fr)`，**不要**用 `1fr`，否则长标题会撑破）；弹窗改为底部抽屉。
- 表格放在可横向滚动的容器里，页面本身**绝不**出现横向滚动。
- 所有可点击元素点击区域 ≥ 44px；手机上输入框字号 ≥ 16px。

## 4. 主题（必须）

- 三档：**系统 / 浅色 / 深色**，默认"系统"。
- 实现：在 `<html>` 上设置 `data-theme="light|dark"`；选"系统"时移除该属性。选择存 `localStorage`（键名 `theme`），读写包 try/catch。
- 防闪烁：在 `<head>` 里、样式之前内联执行（变量名不要用 `t`，避免和 i18n 的 `t()` 冲突）：

```html
<script>
  try {
    var savedTheme = localStorage.getItem('theme');
    if (savedTheme === 'light' || savedTheme === 'dark') document.documentElement.dataset.theme = savedTheme;
  } catch (e) {}
</script>
```

- 切换控件：侧栏底部一个图标按钮，点击弹出三项菜单（Monitor / Sun / Moon 图标 + 文字），当前项打勾。
- 暗色下卡片是 `--surface`（比页面底略亮），靠亮度差而不是阴影区分层级。每个新界面都要在两种主题下各看一次。

## 5. 双语 i18n（必须）

- 支持 `zh`（简体中文）和 `en`。默认取 `navigator.language`（以 `zh` 开头 → zh，其余 → en），用户选择存 `localStorage`（键名 `lang`）。
- **所有**界面文案放进字典文件（如 `src/i18n/zh.ts`、`src/i18n/en.ts`，或对应框架的 i18n 库），组件里不写死中文或英文字符串。两个字典的 key 必须一致，新增文案同时补两种语言。
- key 用语义命名：`task.list.empty.title`，不要用 `text1`。
- 设置 `<html lang="zh-CN|en">`，随切换更新。
- 日期、数字、相对时间用 `Intl.DateTimeFormat` / `Intl.NumberFormat` / `Intl.RelativeTimeFormat`，跟随当前语言。
- 布局要能容纳英文比中文长 30–50%：按钮和标签不写死宽度，允许换行或截断（截断时 `title` 属性给全文）。
- 切换控件：侧栏底部，显示"中 / EN"，点击直接切换，不需要刷新页面。

### 文案风格
- 中文：简短、直接、用动词开头（"新建任务"而不是"点击这里来创建一个新的任务"）。不用感叹号，不用"亲""哦"，不卖萌。中英文和数字之间加空格。
- 英文：Sentence case（"New task"，不是 "New Task"）。
- 按钮写动作结果（"删除 3 个文件"），不写"确定 / OK"。
- 错误信息写三件事：发生了什么 + 可能原因 + 用户能做什么。不要只显示"出错了"或原始异常堆栈（堆栈可以放在"查看详情"折叠区）。

## 6. 组件规范

### 波纹反馈（必须）
- 以下元素**必须**加 `data-ripple`：按钮（所有类型）、侧栏导航项、可点击的列表项和表格行、可点击卡片、菜单项、分段控件、图标按钮。
- 以下元素**不加**：输入框、下拉框、正文里的文字链接、不可点击的容器。
- 波纹颜色自动跟随元素文字颜色：主按钮上是白色波纹，普通按钮上是深色波纹。不单独设置颜色。
- 波纹只是"按下"反馈，**不能替代** hover 样式和焦点环；hover 依旧要有底色或阴影变化。
- disabled、`aria-busy="true"` 的元素不出波纹（`ripple.js` 已处理）；`prefers-reduced-motion` 下关闭（已处理）。
- 实现：`ripple.js` 用事件委托，全局初始化一次。React/Vue 组件里只需要在根元素上写 `data-ripple`，不要为每个组件单独实现波纹。

### 按钮
| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | `--primary` 填充、`--on-primary` 文字、`--primary-shadow`；hover 变 `--primary-hover` 并上移 1px | 每屏最多一个 |
| 次级 | `--surface` 背景 + `--border-strong` 描边 | 常规操作 |
| 浅色 | `--primary-soft` 背景 + `--primary-text` 文字，无描边 | 卡片内的次要强调操作（如"添加内容源"） |
| 幽灵 | 透明，hover 时 `--surface-hover` | 工具栏、列表行内操作 |
| 危险 | `--danger` 填充、`--on-danger` 文字 | 只出现在确认框内 |

- 高度 40px（`--control-h`），页面主操作 44px，行内紧凑 32px；水平内边距 16–22px；圆角 12px；字号 14–15px，字重 600。
- 图标按钮必须有 `aria-label` 和 tooltip。
- disabled：50% 不透明度 + `cursor: not-allowed`。loading 见第 7 节。

### 输入与表单
- 输入框高 40px，圆角 12px，`--surface` 背景 + `--border-strong` 描边；聚焦时描边变 `--primary` 并出现 3px `--ring` 外圈。
- 标签在输入框**上方**，13px，`--fg`，字重 500；必填项不加红色星号，改为在可选项后标"（可选）"。
- 帮助文字在输入框下方，12px，`--fg-subtle`。
- 校验：失焦时校验，提交时全部校验；错误显示在字段下方（`--danger`，12px），描边变 `--danger`；提交失败时焦点移到第一个错误字段。
- 表单底部操作栏：主按钮在右，取消在其左。回车提交单行表单；多行文本框用 Cmd/Ctrl+Enter 提交。

### 列表（卡片内）
- 列表项：内边距 16px 12px，圆角 12px，hover 时 `--surface-hover`；项与项之间 1px `--border` 分割线，用伪元素左右各缩进 12px 画（不要用 border-top，否则和圆角相交会出现断口），hover 时隐藏相邻分割线。
- 结构：状态圆点（10px，外加 4px 同色 `-soft` 光圈）→ 主标题（15px/600，单行截断）+ 次要信息（13px，`--fg-muted`）→ 行尾操作（幽灵图标按钮，`more-vertical`）。
- 子项需要独立感时（如项目列表）：每项 1px `--border` 描边、圆角 12px、项间距 10px，hover 时 `--shadow-card`；左侧放 40px 首字母头像块（`--primary-soft` 底 + `--primary-text` 字）。

### 表格
- 放在卡片里；表头 `--bg` 背景、13px、`--fg-muted`、字重 600；行高 56px；行间 1px `--border`；hover `--surface-hover`。
- 数字列右对齐 + 等宽数字；时间显示相对时间，hover 显示绝对时间。
- 行内操作 ≤ 2 个用幽灵图标按钮，更多收进"更多"菜单。

### 徽标与状态
- **状态**：圆点 + 文字，如 `● 运行中`。色：运行中 `--blue`、成功 `--success`、失败 `--danger`、等待 `--warning`、草稿 `--fg-subtle`。
- **胶囊**：`--xxx-soft` 底 + `--xxx` 文字，12px/600，圆角 full，内边距 3px 10px。
- **类型标签**（如 WordPress）：`--primary-soft` 底 + `--primary-text` 字，11px/700，圆角 8px，可全大写。

### 弹窗与浮层
- 弹窗只在必须打断用户时使用。宽 480px（表单可到 640px），圆角 16px，内边距 28px，阴影 `--shadow-popover`，遮罩 `--overlay`。
- 下拉菜单：圆角 12px，内边距 6px，菜单项高 40px、圆角 8px、带 `data-ripple`。
- Esc 关闭、点遮罩关闭（有未保存内容时先确认）、打开时焦点进入、关闭时焦点回到触发元素。

### 快捷键（建议）
- `Cmd/Ctrl+K` 打开搜索或命令面板（项目有搜索时）；`Esc` 关闭浮层；`/` 聚焦搜索框。
- 快捷键在 tooltip 和菜单里用 `<kbd>` 标出来。

## 7. 状态与反馈（必须）

### 每个数据区块都要实现三种状态
1. **加载**：首次加载用骨架屏（`.skeleton`，形状贴近真实内容：统计卡片要有图标块、标签、数字三块骨架）；刷新已有数据时保留旧内容，**不要**清空后再显示骨架。
2. **空**：48px 色底图标块（`--neutral-soft` 底 + `--fg-subtle` 图标）+ 16px 标题 + 一句话说明为什么是空的 + 一个浅色按钮做下一步（"添加内容源"）。搜索或筛选结果为空时，提供"清除筛选"。
3. **错误**：48px 图标块（`--danger-soft` 底 + `--danger` 图标）+ 原因 + "重试"次级按钮；出错范围限制在出错的卡片里，不让整页白屏。

### 提交与异步操作
- 点击后按钮立即进入 loading：按钮内 spinner 替换图标，文字保留，按钮禁用，**宽度不变**。
- 耗时超过 1 秒显示进度；超过 10 秒的长任务（抓取、生成、导出）必须显示：进度或阶段、已用时间、取消按钮。允许用户离开页面，任务在列表里继续显示状态。
- 能乐观更新的（勾选、重命名、排序）就乐观更新，失败时回滚并提示。

### 反馈位置：就地为主，toast 兜底
- 表单错误 → 字段下方。
- 局部操作结果（保存设置、复制）→ 就地变化（按钮短暂显示"已保存"加勾选图标 1.5 秒）。
- 异步操作的成功/失败、后台任务完成 → toast。
- Toast：右下角（手机上为顶部居中），`--surface` 背景、圆角 12px、`--shadow-popover`，左侧状态图标；最多同时 3 个；成功 4 秒后自动消失；**失败不自动消失**；可以带一个操作按钮（"撤销""查看""重试"）。

### 危险操作：可撤销优先
- 能软删除或能恢复的（删除条目、移出列表、归档）：**直接执行**，弹出带"撤销"按钮的 toast（持续 6 秒），期间撤销则完全恢复。
- 不可恢复的（永久删除、清空数据、覆盖文件、影响外部系统）：弹确认框。标题写清后果（"永久删除 3 个文件？"），正文说明不可恢复，确认按钮用危险样式并写明动作（"永久删除"），默认焦点在"取消"上。
- 批量操作的确认框里写出数量。

---

## 8. 可访问性下限（必须）

- 文字对比度 ≥ 4.5:1（token 已满足）。换主色时验证：`--on-primary` 对 `--primary`、`--primary-text` 对 `--surface` 都要 ≥ 4.5:1。
- 键盘可以完成所有操作；焦点环可见（token 已定义 `:focus-visible`），**禁止** `outline: none` 且不给替代样式。
- 语义化元素：按钮用 `<button>`，链接用 `<a>`，不用 `div` + onClick 代替。
- 状态不能只靠颜色表达（状态圆点旁边必须有文字）。
- 尊重 `prefers-reduced-motion`（token 和 ripple.js 已处理）。

---

## 9. 动效（建议）

- hover 150ms，展开/浮层出现 200ms，波纹 450ms，缓动 `--ease`。
- 主按钮、可点击卡片 hover 时可以上移 1px 并加深阴影；其余元素只变底色。
- 浮层出现：透明度 + 4px 位移。不用弹跳、缩放回弹、旋转。
- 不做页面载入动画、滚动触发动画、数字滚动计数。
